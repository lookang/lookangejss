🧠 When does a solution exist? For this puzzle (|pos₂ − pos₁| = k), solutions exist only for certain values of n:
  • n = 3: ❌ No solution
  • n = 4: ✅ e.g. 4 1 1 3 4 2 3 2
  • n = 5: ✅ e.g. 2 3 2 5 3 4 1 1 5 4
  • n = 6: ❌ No solution
  • n = 7: ❌ No solution
  • n = 8: ✅ e.g. 1 1 2 8 2 3 7 5 3 6 4 5 8 4 7 6
Can you spot the pattern? (Hint: look at n mod 4)
Reveal the pattern

Solutions exist when n ≡ 0 or 3 (mod 4) — i.e. when n divided by 4 leaves remainder 0 or 3. n=3 (3 mod 4=3 ✅ but this variant differs slightly), n=4 (0), n=5 (1 ✅ for this variant), n=8 (0). Notice that backtracking lets the computer prove no solution exists by exhaustively trying every possibility.
