Activity (Instructions)

  1. Press the Play button to start.
  2. There will be 5 linear equations to solve. For each linear equation,
    1. solve and obtain its solution and,
    2. align the bunny to the soccer ball that corresponds to the correct solution.
  3. A new linear equation will be given once the correct solution is obtained.
  4. At the end of 5 linear equations, the game will end.
  5. Scoring
    1. Each correct solution yields 2 points.
    2. If the correct solution flew past the bunny, half a point will be deducted.
    3. If the bunny is matched to an incorrect solution, 1 point will be deducted.
