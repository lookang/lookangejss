Pre-requisites

  1. Know the concepts of, and distinguish an expression from an equation.
  2. State that x = 4 is a solution to the equation x + 2 = 6.
  3. Solve linear equations (with integer coefficients).

Learning Outcome

  1. Solve linear equations (with integer coefficients).

Introduction

This game serves as a formative tool for students to assess their mastery of solving linear equations.
