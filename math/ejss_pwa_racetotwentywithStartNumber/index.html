About this Simulation

This interactive game challenges learners to add numbers strategically to reach exactly twenty from a customisable starting point. Players can set their own start number, then take turns adding increments while exploring different pathways to the target. The game develops number sense, addition fluency, and strategic thinking through engaging, hands-on play.

Learning objectives: Develop fluency in addition and number combinations | Apply strategic thinking to reach a target number | Explore multiple pathways to solve the same mathematical problem
