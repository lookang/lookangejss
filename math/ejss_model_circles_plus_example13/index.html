About this Simulation

This interactive simulation helps learners explore composite shapes by combining circles and rectangles. Students can adjust the length and height parameters to visualize how different dimensions affect total area, then calculate the colored shape's area using the formula length × height.

Learning objectives: Understand how to decompose complex shapes into simpler components | Apply length × height calculations to find rectangular areas | Develop visual reasoning skills for composite geometry problems
