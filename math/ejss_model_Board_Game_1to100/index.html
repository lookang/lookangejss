About this Simulation

This interactive snake and ladder game helps learners develop addition and subtraction skills within 100 using the 'jump' strategy. Players move around a numbered board, calculating moves and distances while encountering snakes and ladders that reinforce mental arithmetic. The visual representation of jumps on the board helps students understand number relationships and counting strategies.

Learning objectives: Fluently add and subtract numbers within 100 using strategies such as counting on and the jump method | Apply addition and subtraction skills in a game-based context to build confidence and engagement | Develop mental arithmetic and number sense through repeated practice with visual feedback
