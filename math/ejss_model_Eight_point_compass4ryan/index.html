About this Simulation

This interactive applet helps learners master eight-point compass directions (N, NE, E, SE, S, SW, W, NW) through coordinate-based challenges. Starting from a green square, students identify and navigate to positions using compass directions. Randomised questions and built-in data analytics provide instant feedback and track learning progress over time.

Learning objectives: Identify and name the eight cardinal and intercardinal compass directions accurately | Locate coordinates using compass notation from a reference point | Develop spatial reasoning and directional literacy skills
