Sun Game Objective: Activate the correct edges so that the number of active edges connected to each node corresponds to the number on that node. Controls: Click an edge once to activate it, a second time to flag it as impossible, and a third time to return it to undecided.

Teacher tools: Use Hint for the next logical observation, Next Step to demonstrate it, Play Thinking to walk through the deduction, and Solve Now when you want the computer to finish the board.
