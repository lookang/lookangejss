Sun Game Objective: Activate the correct edges such that the number of active edges connected to each node / vertice corresponds to the number on that particular node Controls: Click an edge once to active it, a second time to flag it, and a third time to reset it. (Functionally, a flagged edge and an inactive edge are the same. However, they are visually different, and can help players distinguish between an edge that is confirmed to be inactive, and an edge that is still undecided)
