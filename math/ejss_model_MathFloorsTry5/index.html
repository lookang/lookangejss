About this Simulation

This interactive simulation helps primary students solve real-world floor-based math problems. Learners explore clues about which floor people live on by using logical reasoning, number comparisons, and mathematical deduction. The simulation adapts to different device sizes and supports mobile learning on iOS and Android platforms.

Learning objectives: Develop logical reasoning and deductive problem-solving skills | Apply number comparison and ordering to solve multi-step problems | Build confidence in mathematical thinking through interactive exploration
