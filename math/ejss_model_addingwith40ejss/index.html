About this Simulation

This interactive simulation helps learners visualise addition and subtraction within 100 using dynamic visual representations. Students can manipulate variables A, B, C, and D to explore number combinations, solve generated questions, and discover relationships between numbers through hands-on experimentation and immediate feedback.

Learning objectives: Fluently add and subtract two-digit numbers using mental and written strategies | Develop number sense and understand place value to 100 | Apply arithmetic skills to solve practical problems with visual support
