About this Simulation

This interactive simulation lets students practise counting money using Australian coins (10c, 20c, 50c, and $1). Learners select and combine different coin denominations to reach target amounts, building fluency with money values and mental arithmetic. The visual bucket interface makes coin manipulation engaging and intuitive.

Learning objectives: Recognise and identify the value of different coin denominations | Calculate total amounts by combining multiple coins | Apply addition and counting strategies to solve real-world money problems
