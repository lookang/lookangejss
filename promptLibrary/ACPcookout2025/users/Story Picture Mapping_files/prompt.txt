Learning Objectives: 
 
提升学生的场所行为认知
 
 
Interactive Prompt: 
I want to design a concept mapping interactive for my students.

 

 

Grade level: Primary 3

Subject: Chinese language

 

Student readiness level:"Lower Progress (need more support)"

 

 

The concept mapping focuses on: matching pictures to the correct scenario

 

 

The objective of the concept map is to: train students to see linkage among pictures in a story

 

 

While creating the concept map, students should experience: dragging concepts to create connections, seeing visual links between related ideas, building a complete picture of how everything fits together

 

 

The interface should include: draggable text boxes, connecting lines that appear when linking, color-coded categories, zoom buttons, print button, example template overlay
