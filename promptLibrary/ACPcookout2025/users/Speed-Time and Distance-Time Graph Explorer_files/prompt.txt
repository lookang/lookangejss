Learning Objectives:
Understand the relationship between distance-time graph and speed-time graph
 
Interactive Prompt:
Create an HTML5 interactive tool for secondary school mathematics students of age 15 years old to explore the relationship between speed-time graphs and their corresponding distance-time graphs.
 
The tool should include:
A split-screen layout: left panel shows a speed-time graph, right panel shows the corresponding distance-time graph.
Interactive controls to toggle between different speed-time graph types:Constant speed (horizontal line)
Increasing speed (upward slant)
Decreasing speed (downward slant)
Piecewise speed changes (e.g. horizontal then slanted)
Real-time animation of a moving object that reflects the speed profile.
Dynamic plotting of the distance-time graph as the object moves.
Optional step-by-step mode to pause and observe changes at each time interval.
Labels and tooltips to explain key features (e.g. slope, area under curve, gradient).
