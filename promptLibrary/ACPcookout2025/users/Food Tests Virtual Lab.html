Food Tests Instructions

Iodine Test (Starch): Add iodine solution. Blue-black = starch present.
Benedict's Test (Reducing Sugar): Add Benedict's solution, heat. Green/orange/red = sugar present.
Biuret Test (Protein): Add Biuret reagent, wait. Violet = protein present.
Ethanol Test (Fats): Add ethanol, shake. White emulsion when mixed with water = fats present.
