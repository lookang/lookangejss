📦 Exporting from SLS? See expected ZIP contents

When you export an interactive resource from SLS (Student Learning Space), download the full package — it produces a .zip containing these three files:

📁your-simulation.zip
📄index.html— main entry point (required)
📜script.js— simulation logic
🎨styles.css— layout & styling

✅ Upload the .zip as-is — the library will extract it and serve index.html automatically. Single-file .html exports also work.
