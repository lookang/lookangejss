Experimental Investigation of Vertical Oscillator              LO (b)

Here is an illustration of how the oscillation of a basic spring-mass system can be investigated using motion sensor.

  1. Setup the experiment as shown
  2. Displace the mass vertically downwards and release it with initial velocity =0 m/s so that it can oscillate freely in an up and down motion.
  3. Start the data logger when the oscillations are steady.
  4. The motion sensor detects the variation with time of height h.
