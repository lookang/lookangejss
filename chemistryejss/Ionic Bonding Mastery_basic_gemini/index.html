Learn how to form ionic compounds!

Goal: Combine positive ions (cations) and negative ions (anions) to create neutral compounds.

How to Play:

  1. Select one blue cation and one red anion from the pools.
  2. Enter the correct subscripts (how many of each ion) needed to make the total charge zero. (Leave blank or use '1' if only one is needed).
  3. Click "Check Formula".
  4. Hints are available if you get stuck!
