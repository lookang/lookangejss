EXERCISE 2: THE TEM00 MODE: A CONTOUR PLOT

(a) A filled contour plot is a plot that indicates value by color as a function of two variables. Make a plot of the irradiance versus the variables x and y for −2w0≤x,y≤2w0, with w0=0.5 mm and P0=1.0 mW.

(b) Using the same values for w0 and P0, make a filled contour plot of the scaled irradiance I(x,y)/(2P0/πw20) versus the scaled variables x~ and y~ for −2≤x~,y~≤2.
