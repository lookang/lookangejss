🚀 Enhanced for SLS Compatibility

Click to learn more about SLS compatibility

What this tool now does:

  • ✅ Detects external URLs in your HTML, CSS, and JavaScript
  • ✅ Automatically downloads external files (CDN libraries, stylesheets, etc.)
  • ✅ Updates your code to reference local files instead
  • ✅ Creates a README with SLS compatibility notes
  • ✅ Generates truly self-contained ZIP files

SLS Environment Limitations:

  • ⚠ No internet access for external resources
  • ⚠ Strict Content Security Policy
  • ⚠ Limited JavaScript execution capabilities
  • ⚠ Some modern web APIs may be restricted

Tip: For best SLS compatibility, use vanilla JavaScript and avoid complex external libraries when possible.

Supporting Technology-Transformed Learning

This tool supports the spirit of MOE's EdTech Masterplan 2030, whose vision is technology-transformed learning for a technology-transformed world. It helps educators convert interactive HTML lessons into self-contained SLS-ready ZIP packages, so technology-enabled learning resources can be used reliably, shared more easily, and adapted by other teachers.

  • Enhancing teaching and learning: packages interactive lessons, media, scripts, styles, and required external resources so classroom activities can run smoothly in SLS, including when internet access to CDNs is unavailable.
  • Multiplying educator capability: reduces the technical work of preparing offline-ready resources, freeing teachers to focus on lesson design, pedagogy, and meaningful use of technology.
  • Building digital readiness: encourages students and teachers to use, adapt, and understand interactive digital resources as part of everyday learning in a technology-rich environment.
