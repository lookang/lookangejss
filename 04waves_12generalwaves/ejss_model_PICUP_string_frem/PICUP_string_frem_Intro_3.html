Part 1: Modeling

The goal of this project is to numerically calculate the vibrations of a stretched string of total mass MM, unstretched length LL, Young’s modulus YY, and cross-sectional area AA.You will do this by modeling it as a series of N+1N+1 point masses of mass mm connected by NN Hooke’s-law springs, each of equilibrium length r0r0and spring constant kk.

Recall that the spring constant KK of the overall spring is given by K=AY/LK=AY/L. The variables AA and YY only appear in the combination AYAY; it is useful to define this as the “stiffness”, γ≡AYγ≡AY.

  • What mass mm should the point masses have, and what equilibrium length r0r0 and spring constant kkshould the springs have, in order for the properties of the model to match the properties of the string itself?
